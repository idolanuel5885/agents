## שני משתנים שקובעים את מבנה הדוח

### משתנה 1: מטרת חוות הדעת
```
שוק        → דוח בסיסי (חלקים 01-06)
תקן_19     → דוח בסיסי + שווי 85% + חלק 07 (נספח מיסוי)
פינוי_בינוי → דוח בסיסי + חלופה א' + חלופה ב' (שווי עתידי)
```

### משתנה 2: סוג הזכויות
```
בעלות_פרטית    → נסח טאבו בלבד
חכירה_רמי      → נסח + חוזה חכירה + אישור זכויות מרמ"י
חכירה_חברה     → נסח + הסכם רכישה + אישור זכויות מחברה משכנת
```

## קלט נדרש מהשמאי (לכל דוח)

### שדות חובה
- כתובת מלאה
- גוש / חלקה / תת חלקה
- שם לקוח + תואר
- מטרת חוות הדעת
- מספר חדרים
- קומה
- כיווני אוויר
- שטח רשום (מהטאבו)
- שטח בנוי (מהיתר)
- שטח מרפסת (אם יש)
- הצמדות (חניה / מחסן / גינה)
- סוג הזכויות
- שנת בניית הבניין
- מצב היתר (על פי היתר / חריגות)
- רמת גמר (בסיסית / טובה / טובה מאוד)
- גובה פנים
- האם מושכרת + פרטי שכירות

### שדות אופציונליים
- מספר חוות דעת (אם לא אוטומטי)
- הסכם רכישה (לחכירה)
- פרטי פינוי-בינוי (אם רלוונטי)
- תאריך + מחיר רכישה (לנספח מיסוי)

## הנחיות לכתיבה כלליות (לכל החלקים)
- שפה: עברית רשמית, גוף שלישי
- "נשוא חוות הדעת" = הנכס המוערך
- "הח"מ" = השמאי (החתום מטה)
- "שבנדון" = הנכס הנדון
- תאריכים: כתובים במילים לתאריך הקובע ("6 ביולי 2025"), ספרות לאחרים
- סכומים: X,XXX,000 ₪ + כתיב במילים בשומה הסופית
- שטחים: תמיד "כ-" לשטחים בנויים, ללא "כ-" לשטחים רשומים
