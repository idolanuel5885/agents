# SKILL: כותרת ופתיח

## מה זה
החלק הראשון בכל דוח. מופיע פעמיים — פעם אחת בכותרת הדף הראשון (טבלה), ופעם שנייה בגוף המכתב.

## מקור המידע
כולו מהקלט — אין מידע שנאסף אוטומטית.

## שדות נדרשים
- מספר חוות דעת (מספר רץ)
- תאריך
- שם לקוח (כולל תואר: מר / גב' / חברה)
- כתובת הנכס המלאה
- גוש, חלקה, תת חלקה
- מטרת חוות הדעת (ראה אפשרויות למטה)

## אפשרויות מטרה
- `שוק` → "אומדן שווי שוק בין קונה מרצון למוכר מרצון"
- `תקן_19` → "אומדן שווי לצורך בטוחה למתן אשראי לפי תקן 19"
- `פינוי_בינוי` → "אומדן שווי שוק בין קונה מרצון למוכר מרצון" (עם ציון מפורש שיש שתי חלופות)

## פורמט הכותרת (טבלה עליונה)
```
חוות דעת - שומת מקרקעין [מלאה — אם תקן 19 או פינוי בינוי]
הנדון: אומדן שווי [סוג הנכס]
[פרטי גוש/חלקה/תת חלקה]
[כתובת מלאה]
```

## פורמט גוף המכתב
```
[תאריך]
חוות דעת מספר: [מספר]

לכבוד
[שם לקוח]
[א.ג.נ / ג.נ]

חוות דעת - שומת מקרקעין [מלאה]
הנדון: אומדן שווי [סוג הנכס]
[פרטי גוש/חלקה]
[כתובת]

בהתאם לבקשתך/בקשתכם, ערכנו חוות דעת ביחס לשווי [הנכס שבנדון / השוק של הנכס שבנדון] לצורך [מטרה] ולהלן חוות הדעת:
```

## כללים
- גברים: "לכבוד מר X, א.ג.נ"
- נשים: "לכבוד גב' X, ג.נ"
- חברה: "לכבוד X בע"מ, א.ג.נ"
- בנק: "לכבוד [שם הבנק], א.ג.נ"
- מספר מזמינים: מפרטים את כולם שורה-שורה
- המילה "מלאה" מופיעה בכותרת רק בדוחות תקן 19 ופינוי-בינוי
