# SKILL: נספח מיסוי

## מה זה
נספח נפרד שמופיע רק בדוחות תקן 19 (בטוחה לאשראי).
הוא מחושב בנפרד מגוף הדוח ומוצג כמכתב נפרד עם אותה כותרת.

## מתי לכלול
רק כאשר: `מטרת_חוות_הדעת = תקן_19`

## מבנה המכתב

### כותרת (זהה לדוח הראשי)
```
[תאריך]
חוות דעת מספר: [מספר]

לכבוד
[שם מזמין]
א.ג.נ

נספח מיסוי
הנדון: [זהה לכותרת הדוח הראשי]
```

### פתיח
"בהתאם לבקשתכם, להלן תחשיב שווי הנכס נטו לאחר הפחתות בגין עלויות צפויות בעת מימוש:"

### תוכן

#### קביעת חבות מס שבח
- בדוק תאריך רכישה + מחיר רכישה
- אם מחיר הרכישה נמוך משווי הנכס הנוכחי → חבות מס שבח
- שיעור מס שבח סטנדרטי: 25%

ניסוח:
```
• הנכס שבנדון נרכש בתאריך [X] בתמורה לסך של כ-[Y] ₪.
  שווי הנכס גבוה מעלותו באופן בו צפויה לחול חבות במס בעת מימוש
  (הובא בחשבון מס שבח בשיעור של 25%).
```

#### תחשיב עלות שחזור (Replacement Cost)
לצורך חישוב שווי נטו:
```
כ- X מ"ר בנוי × Y ₪/מ"ר
+ כ- Z מ"ר מרפסת × W ₪/מ"ר
+ מחסן + חלק יחסי ברכוש המשותף
+ הוצאות תכנון ופיקוח
+ מע"מ
```

#### טבלת שווי נטו
```
שווי השוק (ברוטו)        : X,XXX,000 ₪
הפחתת מס שבח (25%)       : (XXX,000 ₪)
הפחתת עמלת תיווך (2%)    : (XX,000 ₪)  [אם רלוונטי]
שווי נטו למימוש          : X,XXX,000 ₪
```

## כללי כתיבה
- הנספח הוא מסמך נפרד — מתחיל בדף חדש
- אם לא ידוע תאריך / מחיר רכישה → לציין "לא הוצג בפני הח"מ"
- אם הנכס פטור ממס שבח (דירת מגורים יחידה) → לציין את הפטור
- תחשיב עלות שחזור הוא לצורך הבנת שווי הנטו בלבד, לא ניתוח שמאי נפרד
